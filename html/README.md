# Forno optimized demo

这是一个不依赖构建工具的单页优化版本，直接打开 `index.html` 即可预览，也可以使用任意静态服务器运行。

## 本次优化

- 首屏压缩文案层级，保留清晰的预约和菜单主行动按钮。
- 增加营业状态浮层、预约弹窗、菜单分类筛选和移动端底部快捷栏。
- 用数字化信任条展示认证、评分、距离和营业时间，方便快速扫描。
- 通过 `clamp()`、安全区域间距和响应式栅格适配手机、平板和桌面。
- 增加 skip link、键盘焦点样式、语义化标签、对话框和 `prefers-reduced-motion` 支持。

## 接入真实数据

- 在 `index.html` 中替换 Unsplash 图片地址为餐厅自己的压缩 WebP 图片。
- 将 `data-booking-form` 的提交逻辑接入实际订位服务。
- 将营业时间、电话、地址和菜单价格替换为真实业务数据。
